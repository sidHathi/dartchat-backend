# Dartchat Backend Node Server
 This repo contains the backend node.js code for the Dartchat encrypted messaging service. Important directories include [controllers](src/controllers), where incoming http requests are handled. [services](src/services), which contains the bakend logic, [models](src/models) where I define the data structures for the code, and [sockets](src/sockets) where I handle the socket.io routing logic.
